# Lab 4: Neural Networks

This repository contains code for Lab 4 of the MSAI course, focusing on neural networks for regression and classification tasks.

## Files

- `train.py` - Training utilities for PyTorch models (full-batch training and evaluation)
- `stage_a_regression.py` - California Housing regression model using MLP
- `stage_b_classification.py` - Iris classification model using PyTorch
- `day1_regression_starter.ipynb` - Jupyter notebook for Day 1 regression
- `day2_classification_starter.ipynb` - Jupyter notebook for Day 2 classification
- `requirements.txt` - Project dependencies
- `.gitignore` - Excludes `data/` and `__pycache__/`

## Running

```bash
python stage_a_regression.py
python stage_b_classification.py
```
