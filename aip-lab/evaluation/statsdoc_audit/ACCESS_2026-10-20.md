# StatsDoc access record — 2026-10-20

What was measured about the MoSPI StatsDoc AI Assistant pilot
(`https://statsdoc.ai.mospi.gov.in/`) on 2026-10-20, before any comparison
is drawn. Everything here is reproducible with `scripts/statsdoc_probe.py`
(credentials from the environment; they are never stored in this repo).

## 1. The pilot is account-gated (was: open)

Observed 2026-10-20:

- `GET /` → 200, but the SPA renders the **login page**
  ("MoSPI StatsDoc AI Assistant βeta — AI-Enabled Intelligent Search Solution
  for Documents"; email/username + password, "Sign in", "Sign up",
  "Verify email").
- `GET /c/2402` (a chat URL cited in the v1 notes) → **redirects to
  `/login?redirect=%2Fc%2F2402`**. The session pages that the earlier
  observation used are no longer publicly readable.
- `POST /api/login/` with a wrong pair → `401 {"detail":["Invalid credentials."]}`.
- After a handful of attempts the endpoint answers
  **"Request was throttled. Expected available in 3263 seconds."** — the
  probe script therefore backs off and retries rather than trying anything
  else.

Consequence for the audit: the chat protocol can only be re-run with an
account. The v1 observations in `PROTOCOL.md` predate the login wall and
stay labelled as anecdotal until the archived transcripts land in
`sessions/<date>/`.

## 2. What the pilot offers (from the signed-in surface)

- **Document-scoped chat.** The landing panel says: *"I am MoSPI StatsDoc AI
  Assistant — Select document and start conversation with that!"* A chat is
  bound to a selected document, not to the whole corpus.
- **35 knowledge categories** (native `<select>`, values 59–100):
  Report · National Accounts Statistics · Crop Statistics · Economic Census ·
  Agricultural Statistics Manuals · Index of Industrial Production · Women
  and Men in India 2025 · 77th Round (SAAH & LH) · 70th Round Key
  Indicators · Unincorporated Sector Establishment And Household · Energy
  Statistics · CAPEX · ASUSE · GDP · Consumer Price Index · National
  Metadata Structure · Nutritional Intake · Miscellaneous · PLFS Reports ·
  PLFS Instruction Manuals · SDG · QBUSE · 80th Round (CMS, NHTS & DTES) ·
  NHIS Instruction Manuals · Infrastructure Performance Reports · Indian
  Statistical Institute Reports · HCES Reports · Flash Report on Central
  Sector Infrastructure Projects · Environmental Accounting Instruction
  Manuals · Environment Statistics · Compendium of Datasets and Registries ·
  Children in India · ASI · ASUSE Instruction Manuals · 80th Round
  Instruction Manuals.
- **Three languages** for the assistant: English, Hindi, Kannada.
- Account chats are persistent and visible in the sidebar (the account used
  for this audit already contained *"How much has real rural MPCE grown
  between 2011-12…"* — protocol prompt 2, asked by hand).

## 3. The data layer underneath it (measured, public)

`https://api.mospi.gov.in` (eSankhyiki) answers the same questions
statistically, with no login:

| Probe | Result |
|---|---|
| PLFS filters | 10 filter groups returned (state/indicator/year/sector/gender/age/status…) |
| Madhya Pradesh, female, urban, 15+, LFPR 2023-24 | **28.5 %** (PS+SS) and **24.7 %** (CWS), plus 9 education sub-cuts (35.9 / 34.3 / 27.0 / 18.4 / 16.5 / 61.3 / 27.1 / 35.5 / 23.8) |
| PLFS "2027" (a forecast year) | `{"data":[],"msg":"No Data Found"}` — the API has no future round; anything quoted for 2027 would be generated, not retrieved |
| Latency | 0.3–0.4 s per PLFS query |

So the state-wise labour cuts that Vidhi's PDF store does not carry *do*
exist in the MoSPI data layer — which is why Vidhi keeps a live
"SOURCED (not certified)" tier beside its VERIFIED tier.

## 4. Files in this folder

- `PROTOCOL.md` — the re-runnable prompt set and the citation rules.
- `sessions/<date>/` — archived transcripts (text + screenshot + URL +
  timestamp) for every protocol prompt, on both systems.
- `COMPARISON.md` — what each system has, and where each one is better.
