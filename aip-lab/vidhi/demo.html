    How checking works

    Question → typed claim → five rule stages (safety, scope, comparability, metadata, numeric) → verdict frozen with SHA-256 before any document is read → evidence retrieved → answer rendered with citations. Untrusted text can never change the verdict. Only verified rows can pass.

    Safety-A runs first and blocks prompt injection in English, Hindi and Hinglish. Comparability rules are versioned data (data/vidhi/comparability_rules.yaml v3, all active with verbatim MoSPI quotes), not hidden prompts.
