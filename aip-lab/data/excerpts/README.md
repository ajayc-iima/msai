# Excerpts — official evidence only

Place small curated `.md` files here with YAML front-matter:

```yaml
excerpt_id: PLFS_2022_23_DEF_USUAL_001
citation_id: CIT_PLFS_001
survey: PLFS_2022_23
round: "2022-23"
source_document: PLFS_2022_23_Annual_Report.pdf
page: "p.X"
table_or_section: "Section Y"
topic: definition_usual_status
adversarial: false
verbatim: true
source_url_or_path: data/raw/PLFS_2022_23_Annual_Report.pdf
```

Rules:
- Official excerpts must be verbatim or clearly marked `verbatim: false` + paraphrase note.
- Do NOT cite a page absent from `data/citations/citation_index.json`.
- The only synthetic file allowed here is `SAFETY_B_ADVERSARIAL_001.md`.
